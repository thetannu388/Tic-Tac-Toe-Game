Tic Tac Toe Game

A simple Tic Tac Toe game built using HTML, CSS, and JavaScript. Two players can take turns marking X and O on a 3×3 grid, and the game automatically checks for a winner or a draw.

Features

- Two-player gameplay
- Winner detection
- Draw detection
- Reset game option
- Clean and responsive design

Technologies Used

- HTML
- CSS
- JavaScript

How to Play

1. Open the game in your browser.
2. Player X makes the first move.
3. Players take turns placing X and O on the grid.
4. The first player to align three marks horizontally, vertically, or diagonally wins.
5. If all cells are filled without a winner, the game ends in a draw.
